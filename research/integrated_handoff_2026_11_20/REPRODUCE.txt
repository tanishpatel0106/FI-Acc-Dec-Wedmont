Package layout
lifecycle/ contains the complete versioned repository, public snapshots, aggregate evidence and source.
household/scripts/ contains the seven SCF/SHED and international analysis modules used by the new analyses.
household/data/age_expense_extension/ contains the published-method medical-imputation transcription.
output/pdf/ contains the final employer documents.
Public raw household archives and licensed vendor observations are excluded. Official public download
URLs and frozen SHA-256 hashes are supplied in the two input manifests. No credentials are required
for the public analyses or for running the aggregate-only notebook.

Scientific limits
This is an exploratory observational and conditional scenario study. The SCF stress formula is
investigator-defined. SHED supplies independent prospective evidence for an emergency-fund proxy,
not direct validation of that formula. Cross-wave predictive intervals condition on fitted models.
Budget templates are cell means; nonlinear outcomes are not population estimates. Initial allocations
are endowed, income paths are frozen and the model omits career/retirement transitions. No stable CE
superiority, causal aging effect, personal investment mandate or harmonized country ranking is claimed.

One-command Windows application installation
From lifecycle/, run .\setup_windows.ps1 after installing uv and Node.js 22 or newer. This exact
workflow was tested in another fresh clone with freshly installed environments, restored public
snapshot, regenerated studies and production frontend. An optional -UvPython points to a Python
interpreter that provides uv as a module. This does not reuse the backend environment. The receipt
is one_command_install_verification.json and the generated IDs are one_command_public_run_ids.json.
The default classic Permanent Portfolio cannot run without gold in the public snapshot: the tested
installer explicitly computes and labels the ex-gold core-duration variant instead. This capability
boundary is not equivalent to validating a gold-inclusive portfolio with public data. The archive
contains the source and aggregate WRDS gold results, not the licensed raw gold-proxy observations.
