# Visualization index

Generated from `LIFECYCLE_V2_VISUALIZATION_CATALOG.json` and checked against the source: every `viz_id`
below is rendered inside a `VisualizationFrame` (`data-viz-id="VIZ-ID"`) on the unified page listed.
Every frame shows its ID, a data-class tag (Observed / Model-generated / Illustrative / Unavailable), an
**information button** whose panel is generated from `web/lib/research/visualization-registry.ts`
(what it shows, how to read it, calculation, why it matters, interpretation, assumptions & limitations,
live provenance, related research), a CSV export of the derived block and its run ID.

The original modules carried into the unified pages add the IDs listed in the second table. The in-app
reference (Methodology › Visualization reference) is generated from the same registry, so it always
matches the information panels. Deep link: `<route>?section=<section>#<VIZ-ID>`.
